# MediaForge

Assisted media production and a segmented news desk.

Create editable sports posters with Bangla typography, reusable layouts, source credits and an editor approval step. A separate news miner collects and organises stories for review and export.

## Technologies

React · TypeScript · Node.js · SQLite · Canvas

## What it does

- Editable poster layouts and PNG export
- Source attribution and permission notes
- Topic queues, duplicate handling and historical storage

## Current status

Local prototype; synthetic poster workflow demonstrated.

Full implementation remains private. This showcase contains descriptions and approved demonstration material only.

## Recent work

- 2026-10-04 — Poster editing and export demonstrated (Runtime observed): Synthetic input used to inspect controls, preview and PNG output.
- 2026-10-04 — News collection and review workflow prepared (Implemented): Segmented queues, source links and review states available in the local desk.
